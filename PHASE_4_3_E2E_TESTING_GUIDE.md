## Test Files Overview

### File 1: test_e2e_workflows.py

**Purpose:** Core end-to-end workflow testing

**What It Tests:**
- API responsiveness
- Complete user workflows (enroll → verify)
- User isolation and data segregation
- Concurrent user operations
- Database persistence
- Error handling
- Performance metrics
- User state transitions
- Full user journey simulation

**Duration:** ~90 seconds

**Output File:** `e2e_test_results.json`

```bash
python test_e2e_workflows.py
```

### File 2: test_e2e_scenarios.py

**Purpose:** Real-world scenarios and stress testing

**What It Tests:**
- High volume enrollment (20+ users)
- Rapid-fire verification (20+ requests)
- Concurrent mixed operations
- Data consistency under load
- Cross-user security verification
- System recovery and resilience

**Duration:** ~150 seconds

**Output File:** `e2e_stress_test_results.json`

```bash
python test_e2e_scenarios.py
```

## Requirements

### System Requirements

**Operating System:** Windows, macOS, or Linux  
**Python:** 3.8+  
**RAM:** 4GB minimum (8GB recommended)  
**Disk:** 100MB free space  

### Software Dependencies

**Backend (must be running):**
- FastAPI server running on http://localhost:8000
- MongoDB running on localhost:27017
- Python dependencies: `pip install -r backend/requirements.txt`

**Test Dependencies:**
- requests library (included in backend requirements)
- Python standard library (threading, json, statistics, etc.)

## Running Tests

### Method 1: Individual Test Suites (Recommended for Development)

```bash
# Run workflow tests only
python test_e2e_workflows.py

# Run scenario tests only (after workflows pass)
python test_e2e_scenarios.py
```

### Method 2: Sequential Execution (Full Test Suite)

```bash
# Create a batch file (batch_e2e_tests.bat on Windows)
python test_e2e_workflows.py
python test_e2e_scenarios.py
```

Or on Linux/macOS:

```bash
#!/bin/bash
python test_e2e_workflows.py
python test_e2e_scenarios.py
```

### Method 3: Full Automation

Create `run_e2e_complete_suite.py`:

```python
#!/usr/bin/env python3
import subprocess
import sys
import time

print("="*80)
print("COMPLETE E2E TEST SUITE")
print("="*80)

# Generate test audio
print("\n[1/3] Generating test audio...")
result = subprocess.run([sys.executable, "generate_comprehensive_audio.py"])
if result.returncode != 0:
    print("❌ Audio generation failed")
    sys.exit(1)

time.sleep(2)

# Run workflow tests
print("\n[2/3] Running workflow tests...")
result = subprocess.run([sys.executable, "test_e2e_workflows.py"])
if result.returncode != 0:
    print("❌ Workflow tests failed")
    sys.exit(1)

time.sleep(2)

# Run scenario tests
print("\n[3/3] Running scenario tests...")
result = subprocess.run([sys.executable, "test_e2e_scenarios.py"])
if result.returncode != 0:
    print("❌ Scenario tests failed")
    sys.exit(1)

print("\n" + "="*80)
print("✅ ALL E2E TESTS COMPLETED")
print("="*80)
```

Then run:
```bash
python run_e2e_complete_suite.py
```

### Method 4: Continuous Integration (CI/CD)

```yaml
# .github/workflows/e2e-tests.yml
name: E2E Tests

on: [push, pull_request]

jobs:
  e2e-tests:
    runs-on: ubuntu-latest
    
    steps:
      - uses: actions/checkout@v2
      
      - name: Set up Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.10'
      
      - name: Install dependencies
        run: |
          pip install -r backend/requirements.txt
      
      - name: Start services
        run: |
          # Start MongoDB
          docker run -d -p 27017:27017 mongo:latest
          
          # Start backend
          cd backend
          python run.py &
          sleep 5
      
      - name: Generate test audio
        run: python generate_comprehensive_audio.py
      
      - name: Run E2E tests
        run: |
          python test_e2e_workflows.py
          python test_e2e_scenarios.py
```

## Common Issues

### Issue 1: "API is not running"

**Error Message:**
```
❌ API is not healthy - testing cannot proceed
```

**Cause:** Backend server is not running

**Solution:**
```bash
# Terminal 1: Start backend
cd backend
python run.py

# Terminal 2: Run tests
python test_e2e_workflows.py
```

### Issue 2: "Test audio files not found"

**Error Message:**
```
Enrollment audio file not found: test_audio_files/test_speaker1_enroll.wav
```

**Cause:** Audio files have not been generated

**Solution:**
```bash
python generate_comprehensive_audio.py

# Verify files exist
ls test_audio_files/
```

### Issue 3: "MongoDB connection failed"

**Error Message:**
```
Connection to MongoDB failed
```

**Cause:** MongoDB is not running or not accessible

**Solution:**
```bash
# Windows - Check if mongod is running
netstat -ano | findstr :27017

# Start MongoDB (ensure mongod.exe is in PATH)
mongod

# Or use Docker
docker run -d -p 27017:27017 mongo:latest
```

### Issue 4: "Tests timeout"

**Error Message:**
```
Timeout waiting for API response after 30 seconds
```

**Cause:** Backend is slow or network issue

**Solution:**
1. Increase timeout in test file:
```python
requests.post(..., timeout=60)  # Increase from 30
```

2. Check backend performance:
```bash
# Monitor backend logs
# Look for slow model inference
```

3. Restart services:
```bash
# Restart backend
# Restart MongoDB
```

### Issue 5: "Cross-user verification passing (shows as FAIL)"

**Error Message:**
```
✗ Cross-user rejection: Score 0.88 (should not match)
```

**Cause:** Similarity threshold is too low, allowing false positives

**Solution:**
```python
# Edit backend/main.py around line 170
VERIFICATION_THRESHOLD = 0.85  # Increase from 0.75

# Restart backend
cd backend
python run.py

# Re-run tests
python test_e2e_workflows.py
```

### Issue 6: "Performance too slow"

**Error Message:**
```
Enrollment response time: 8.5s (expected < 5s)
```

**Cause:** System performance issue

**Investigation Steps:**
1. Check CPU usage:
```bash
# Windows
wmic os get totalvisiblememorysizeK,freephysicalmemoryK

# Linux
free -h

# macOS
vm_stat
```

2. Check disk speed:
```bash
# Test disk I/O performance
```

3. Profile backend:
```python
import cProfile
import pstats

# Add to backend/main.py
cProfile.run('main()')
```

**Solutions:**
- Close other applications
- Increase RAM allocation
- Use SSD instead of HDD
- Optimize model inference

## Advanced Usage

### Generate Custom Results Report

```python
import json
from pathlib import Path

# Load results
with open("e2e_test_results.json") as f:
    results = json.load(f)

# Generate report
total = results["summary"]["total"]
passed = results["summary"]["passed"]
failed = results["summary"]["failed"]
pass_rate = results["summary"]["pass_rate"]

print(f"Test Results Summary")
print(f"===================")
print(f"Total Tests: {total}")
print(f"Passed: {passed}")
print(f"Failed: {failed}")
print(f"Pass Rate: {pass_rate}")

# Details
for test in results["details"]:
    status = test["status"]
    name = test["name"]
    print(f"  {status}: {name}")
```
